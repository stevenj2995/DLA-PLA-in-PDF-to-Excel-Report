DLA to Excel

Membaca berkas DLA satu perusahaan, lalu menyusunnya jadi satu Excel: parameter di dalam dokumen itu sendiri yang jadi kolom, dan tiap PDF jadi satu baris. Tidak ada template berkolom tetap dan tidak ada penebakan. Nilai diambil mentah persis seperti tercetak di surat, jadi tidak ada tanggal atau angka yang bisa salah ditafsirkan.

Cara menjalankan: install dulu isi requirements.txt, lalu install Tesseract-OCR terpisah (`winget install UB-Mannheim.TesseractOCR`) supaya PDF hasil pindaian bisa dibaca, lalu jalankan run.py dengan python. Setelah itu buka http://localhost:8000 di browser. Halaman dan pemrosesan ada di alamat yang sama, jadi tidak ada yang perlu disetel dan tidak ada urusan CORS.

Semuanya berjalan di laptop ini saja. Server mendengarkan di 127.0.0.1, bukan 0.0.0.0, jadi komputer lain di jaringan kantor pun tidak bisa menghubunginya. Tidak ada terowongan, tidak ada backend di internet, dan dokumen klaim tidak pernah keluar dari mesin ini.

Isi folder secara singkat: run.py menyalakan backend di localhost. Backend/server.py menerima unggahan, mengatur sesi, dan menghapus jejaknya. Backend/pipeline.py adalah alur dari PDF sampai Excel. Backend/profiles.py berisi aturan per perusahaan, kolom apa yang diambil dan dari mana. Backend/extract membaca PDF jadi baris teks lalu jadi pasangan label dan nilai. Backend/build/excel.py menulis sheet hasilnya. Frontend berisi halaman yang disajikan oleh backend di localhost. PDF Files berisi contoh DLA dan tidak ikut masuk git.

Perusahaan yang didukung baru JRP. Askrindo dan KMDastur sudah ditulis sebagai draf di Backend/profiles.py tetapi sengaja belum diaktifkan sampai daftar kolomnya ditinjau, karena profil setengah jadi yang menulis kolom salah lebih berbahaya daripada berkas yang ditolak. Untuk JRP, halaman debit note diabaikan dan hanya halaman DLA yang dibaca. Dari blok nominal hanya nilai nett yang diambil, dan mata uang dipisah jadi kolom tersendiri di sebelah kiri tiap kolom nominal.

Untuk PDF hasil pindaian, halaman yang tidak punya lapisan teks dibaca dengan Tesseract memakai bahasa Indonesia dan Inggris pada 300 dpi. Barisnya dibentuk dari posisi kata, sama seperti jalur PDF digital, supaya hasilnya sebangun. Sudah diuji dengan menjadikan DLA JRP sebagai gambar lalu membacanya ulang, hasilnya 23 dari 24 kolom sama persis dengan hasil PDF aslinya. Yang berbeda satu, tulisan Jl. terbaca sebagai Jl, itu batas OCR yang tidak bisa dihilangkan sepenuhnya. Karena itu setiap berkas yang dibaca lewat OCR ditandai di halaman hasil supaya dicocokkan manual.

Soal privasi, semua pemrosesan terjadi di laptop ini dan tidak ada layanan pihak ketiga yang menyentuh isi dokumen. PDF yang diunggah dihapus begitu selesai dibaca. Excel hasil tersimpan sementara di folder temporary maksimal 15 menit, dan bisa dihapus lebih cepat lewat tombol di halaman hasil. Repo ini publik di GitHub, tetapi gitignore menahan berkas pdf, xlsx, folder PDF Files, dan folder Output. Riwayat git sudah diperiksa, tidak pernah ada satu pun dokumen klaim yang ikut masuk.

vercel.json dan .vercelignore sengaja ditinggalkan meski deployment tidak dipakai. Keduanya membatasi Vercel supaya hanya menyajikan folder Frontend saja. Kalau dihapus sementara integrasi GitHub masih tersambung, Vercel justru akan menerbitkan seluruh repo termasuk kode Python. Untuk benar-benar melepasnya, project-nya harus dihapus dari dasbor Vercel.
